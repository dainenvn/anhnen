# LocofyHost — Website bài tập Figma (bản cập nhật)

Trang chính đã được chỉnh theo ảnh **Cover** Figma do người dùng cung cấp: tiêu đề "Find a host for every journey", thanh tìm kiếm và dữ liệu thẻ chỗ ở vùng Toronto. Các trang chi tiết, đăng nhập, đăng ký giữ thiết kế responsive và tương tác demo.

**Chưa phải bản pixel-perfect:** ảnh hiện tại chỉ là screenshot giao diện Figma zoom 55% trong trang Cover, không có quyền truy cập trực tiếp bộ assets/style của các frames thuộc Getting Started. Hình ảnh được dùng từ Unsplash và chưa khớp toàn bộ hình ảnh gốc.

## Chạy thử
Mở `index.html`, hoặc dùng VS Code Live Server. Đường dẫn đều là tương đối để chạy từ GitHub Pages.

## GitHub Pages
1. Tạo repository public trên GitHub.
2. Upload **nội dung** thư mục này vào nhánh `main` ở root (không đưa riêng file zip lên).
3. Vào Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Chờ trang xuất bản, truy cập URL `https://USERNAME.github.io/REPO/` trong cửa sổ ẩn danh, bấm thử các trang.
5. Chỉ nộp 1 URL website chạy được vào OBE trước 20:00 ngày 26/10/2026.

Các form tài khoản/đặt phòng chỉ mô phỏng phía trình duyệt, không kết nối backend.
